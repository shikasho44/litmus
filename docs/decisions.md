## 2026-09-27 名探偵度数と、その場の「減点」（くられ先生の感想から）

- 監修のくられ先生が遊んだ感想: 「いまはミスをしてもペナルティの実感がない。ミスごとに内部で減点して累計スコアを出し、解決時に探偵レベルを見せ、名探偵度数のランクバッジがあるとよい」。これに沿って実装した（`docs/design-bible.md` §3-6「名探偵度数」）。
- **減点を増やした**: ランク計算（0〜100点）に「ゲームオーバー 1回12点・最大36点」「確認テストのやり直し 1回2点・最大8点」を足した。どちらも事件の難易度によらない。ゲームオーバーは「その事件を最後に解いたとき以降の回数」を数える（`gameOversAtClear` を解決のたびに記録）。審問官・教授ではゲームオーバーで失敗した回の記録が消えるため、これまでは失敗が結果にまったく残らなかった。確認テストのやり直しは記録されていたのに採点されていなかった。
- **減点を見せる**: 囁き・撃ち損じ・泣きつき・死因宣告の失敗・確認テストのやり直しの瞬間に、その操作の横に「減点 −n」を約1秒出す。n はランク計算が実際に引く点（事件の難易度で 8/7/6、4/3.5/3 など。上限に届いたあとは差分、0 なら出さない）。計算の表（`PENALTY_RULES`）を1つにして、画面の数字と結果の数字が必ず一致するようにした。ゲームオーバーと審問中断はその画面の札で示す。先生の言う「ペナルティの実感」は、結果画面より、ミスした瞬間に数字が見えることのほうが効くと考えた。
- **名探偵度数**: 1回の獲得度数 ＝ 事件スコア × 難易度倍率（見習い 0.6 ／ 審問官 1.0 ／ 教授 1.4）＋ S+ ボーナス 10。名探偵度数は事件ごとの最高の合計。周回で稼げないように「最高を超えた分だけ」増える。
- **称号**は絶対値: Lv1 駆け出し探偵 1〜／Lv2 一人前の探偵 120〜／Lv3 腕利き探偵 240〜／Lv4 名探偵 360〜／Lv5 伝説の名探偵 480〜。いまの3事件の最大は 450（全部 教授・S+）なので Lv5 には届かない。事件を足すと届くようになる（割合で決めると、事件を足したときに既存のプレイヤーの称号が下がるため）。値は `src/features/rank/points.ts` の定数だけで調整できる。
- **見せ方**: 設計の正本が「スコアを主役にしない」なので、結果画面ではランクの判子の下の控えめな一枚にした。累計は画面に入ってからカウントアップし、称号が上がった回だけ「ランクアップ！」を短く出す（タップかキーで終わる。動きを控える設定では完成形のみ）。事件ファイルの見出しに小さなメーター、事件タグに最高度数、遊び方に説明ページ、共有文に名探偵度数と称号。バッジは画像ではなく CSS（銅→銀→金→ホルマリン→虹）。
- **セーブ**: すべて省略可能な項目の追加（`bestPoints`・`gameOversAtClear`・`lastResult.prevBestPoints`・`stats.points`）で、`SAVE_VERSION` は上げていない。この日より前に解決済みの事件は、最後の結果の度数を最高として読み込む（本当の最高は残っていないため）。「記録をすべて消去」で度数も消える。
- 確認: `npx vitest run`（新しいテスト: ランクの新しい減点・`penaltyStep` と計算の一致・度数と称号・セーブの最高更新とゲームオーバーの数え方）、`node scripts/shots-score.mjs`（画面写真と実プレイでの減点表示の確認、`qa/score/`）。有料の API は使っていない。

## 2026-09-28 質問枠（質問の予算）と、ホルマのひとりごと
