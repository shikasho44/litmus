2026年9月24日 17:20

調べたところ、「ジェーンドゥの死因」は、くられ氏と薬理凶室が展開している「科学×水平思考×推理」のゲーム企画です。単なるウミガメのスープ系ではなく、科学的な知識を使って「身元不明の人物が、なぜ死んだのか」を推理するところが大きな特徴です。公式では「身元不明の死体の死因を当てる水平思考クイズ」と説明されています。

調査した範囲では、市販のボードゲームやSteamゲームというより、YouTube動画シリーズとリアルイベントで展開されているゲームフォーマットと捉えるのが正確です。2021年11月23日に、くられ氏側のYouTubeチャンネルで第1回が公開されています。

「Jane Doe」という名前自体は、英語圏で「名前の分からない女性」「身元不明女性」などを指す仮名です。身元不明の女性遺体に使われる場合もあります。そのため「ジェーンドゥの死因」という題名そのものが、「身元不明女性の死因を特定せよ」というゲーム内容になっています。


ゲームの基本構造

大まかには次のような進行です。

1. 最初に「ジェーン・ドゥがどのような状態で死亡していたか」という短い状況説明が提示される
2. プレイヤーはゲームマスターに質問したり、与えられた情報から仮説を立てたりする
3. ゲームマスターから回答やヒントが与えられ、情報が徐々に増える
4. 「この人物は何者なのか」「何が起きたのか」「何が死因なのか」を組み立てる
5. 最後に正解と、そこに関係する科学的な仕組みが解説される

実際の視聴者によるプレイ解説では、最初に死亡状況が示され、複数フェーズを通して「ジェーン・ドゥの正体と死因」を推理する形式とされています。別のプレイレポートではYES/NO型の質問から情報を絞っていく形式も確認できます。エピソードによって細かな進行は変わるようです。


普通の「ウミガメのスープ」と何が違うのか

かなり近いゲームですが、大きな違いがあります。

| 要素 | 一般的な水平思考クイズ | ジェーンドゥの死因 |
|---|---|---|
| スタート | 奇妙な出来事 | 奇妙な死亡状況 |
| 目的 | 背景事情を当てる | 身元・状況・死因を解明 |
| 質問 | YES/NO中心 | 質問＋推理＋科学知識 |
| 真相 | アイデア・物語中心 | 科学的現象が重要 |
| 終了後 | 答え合わせ | 科学解説まで行う |
| 雰囲気 | 謎解き | 科学捜査＋水平思考 |

ここがこの企画のかなり良いところです。

「知識があれば即答できるが、知らなくてもヒントから推理できる」

という二重構造になっています。

つまり「科学クイズ」だけにしてしまうと知っている人しか答えられませんが、水平思考形式を入れることで、知らない人でも仮説を立てながら答えに近づけます。


実際の問題の雰囲気

公式ページを見ると、かなり幅があります。例えば、

「舞踏会で急死した女性」
「農家の女性が畑で即死」
「大量の宝石の横で女性が死亡」
「工場員が爆死。しかし爆弾はない」
「水のない場所で溺死」
「手術にミスはなかったのに術後に死亡」
「健康な状態で退院したのに急死」
「探検家を襲った実在する呪い」

などがあります。

重要なのは、単に殺人事件を推理する企画ではないことです。

化学、生物、医学、物理、毒物、環境、人体など、「一見すると不可解だが科学的には説明可能」という現象を死因に使っています。

このため「ミステリーを入口にして科学を学ばせる」という構造になっています。


出演・制作体制

中心となるゲームマスター・出題側は、くられ氏および薬理凶室です。第1回は「主役は我々だ！」とのコラボ企画として公開されています。

複数回でジェーンドゥ役の声を担当しているのが、うるちまい子氏です。イラストには夢路キリコ氏などが参加しています。動画概要欄でもこのクレジットが確認できます。

この「死亡した本人がナレーション・演技によって状況を語る」という演出も、ただ問題文を読み上げるより物語への没入感を上げています。


かなり長く続いている企画です

第1回は2021年11月23日。

その後、2022年以降かなり多数制作され、主役は我々だ！、QuizKnock、ブラックチャンネルなどとのコラボも行われています。公式まとめページには多数のエピソードが掲載されています。

2025年8月にもQuizKnockとの新作が公開されているため、一時期だけの企画ではなく、少なくとも2025年まで継続して展開されています。QuizKnockコラボ動画は2025年8月29日公開です。

人気もかなり高く、2022年1月公開の「舞踏会で急死した女性」の回は2026年時点で約120万再生、「農家のお姉さん」の回も100万再生を超えています。


動画だけではなくリアルゲームにもなっています

ここも重要です。

2022年のニコニコ超会議では「超ジェーンドゥの死因」としてリアル開催されています。公式イベントページでも「大人気、水平思考科学クイズのジェーンドゥがリアルで登場」と紹介されています。

2024年のニコニコ超会議でも「科学推理ゲーム『ジェーンドゥの死因』〜あの子はどうして死んだのか〜」として開催されています。

別イベントでは「全員参加のジェーンドゥの死因オンステージ」として観客参加型でも実施されています。

つまり、

YouTube動画
↓
出演者参加型ゲーム
↓
観客参加型イベント

までフォーマットとして拡張できているわけです。


このゲームが面白い理由

企画構造を分解すると、かなりよくできています。

「死」という強烈な謎から始まり、
「なぜ？」
↓
「質問する」
↓
「仮説を立てる」
↓
「新情報が出る」
↓
「仮説を修正する」
↓
「真相に到達する」
↓
「科学を知る」

という学習ループになっています。

しかも、途中で間違った推理をしても、それ自体が面白くなる設計です。

答えが分からない状態では出演者の回答が大喜利的になることもあり、それも動画としてのエンタメになります。つまり、

正解できる人 → 推理が楽しい
正解できない人 → ボケや仮説が楽しい
視聴者 → 一緒に推理できる
解答後 → 科学知識を持ち帰れる

という4段構造です。


ヨンサンが最近考えている「生成AIを学べるゲーム」との相性で見ると、この構造はかなり参考になると思います。

例えば、

「ある会社で突然AIが使えなくなった。なぜ？」
「AIに正しい資料を渡したのに回答がおかしくなった。なぜ？」
「同じプロンプトなのに結果が変わった。なぜ？」
「100万トークン使えるAIなのに重要な情報を忘れた。なぜ？」

という事件を提示して、

プレイヤーが質問
→ AIキャラクターがYES/NOやヒントを返す
→ 仮説を立てる
→ 真相を当てる
