波の届かない城

入門★1・10〜12分分野：物理・地学監修：不要

事件カード八月の海辺。朝、兄と妹が作った砂の城が、昼すぎに崩れ落ちていた。潮は引いていくところで、波は一度も届いていない。——いったい何が、彼女を崩したのか？

被害者：砂の城（生まれて6時間／役目: 夏休みの思い出）

砂つぶの間の「見えない水の接着剤」という身近な物理が、思いがけない安全の話（砂の穴の事故）につながる。身近な素材の性質をとことん使う、Dr.STONE 的な話。
ネタばれ：「なるほど」の瞬間・真相と科学・ミスディレクション・学べること・安全・出典

「なるほど」の瞬間

  • 城を立たせていたのは、砂ではなく水だった。犯人は波ではなく、太陽と風。「水が足された」から崩れたのではなく、「水がなくなった」から崩れた。

真相と死因の科学

  • 真相: 兄妹は朝、潮が引いたあとの湿った砂で、日なたに大きな城を作った。強い日ざしと海風で、城は外側から乾いていった。砂つぶをつないでいた水がなくなると、塔は乾いた側からさらさらと崩れ、昼すぎに倒れた。テントの影に作った小さな城は、湿ったまま立っていた。波も人も、城にはふれていない。
  • 死因の科学: 湿った砂では、つぶとつぶのすきまに、ごく少しの水が小さな「橋」をつくる。水の表面張力がこの橋を引きしめ、つぶどうしを引きつけるので、砂は固まる。乾いた砂は自分の重さも支えにくい。いちばん強いのは水がほんの少しのとき（体積で約1%）で、乾いても、水が多すぎても崩れる。

ミスディレクションと、その晴らし方・戻し方

  • 波・満ち潮 → 潮見表の看板では引き潮の時間。城のまわりに波の跡（ぬれた筋、打ち上がった貝がら）がない。崩れた砂はさらさらに乾いている。→ 晴れたあと「水が足されたのではなく、なくなったのでは？」へ向かう。
  • 誰かが蹴った（ビーチボールで遊ぶ子、犬の散歩の人）→ 足あとが城まで来ていない。崩れ方が、一方向に倒れた形ではなく、表面から流れ落ちた小山。→ 「崩れ始めたのは日の当たる側・風上」と気づかせ、乾きへ戻す。
  • 導入で見せるもの: 兄妹、日なたの大きな城とテントの影の小さな城、妹のバケツ（朝は城に水をかけていたが、昼は海で遊んでいた）、潮見表の看板、ボール遊びの子と犬の散歩の人。
  • 誤差の例: わたしは[[波に、さらわれた]]。→ 所見「波の跡なし」「引き潮の時刻」を当てる。

学べること／身を守る知恵

  • 濡れた砂は固まるが、乾くと崩れる。
  • 砂浜に深い穴やトンネルを掘ると、砂が崩れて人が埋まることがある（米国で10年に52件、うち死亡31人の報告）。穴はひざより浅く。帰る前に埋め戻す。穴に入らない、人を首まで埋めない。

安全の注意／実在事例・統計

  • 書かないこと: 人が砂に埋まる場面。実在の事故の実名。
  • 実在事例・統計: Maron ほか（NEJM 2007）は、1997〜2007年に遊びで掘った砂の穴の崩落52件（3〜21歳）、うち31人が死亡と報告。米ニュージャージー州労働局（2012）は、穴は小さい人のひざの深さ（約30cm）までにし、埋め戻すよう呼びかけている。日本の件数は未確認。

澄みきったガラスの部屋

入門・正体を伏せる型★1・12〜15分分野：生物・化学監修：不要公式との近さ：要確認 #24

事件カード夏祭りから五日目の朝。彼女は、小さなガラスの部屋の底近くで、もう動かなくなっていた。その部屋は毎朝ぴかぴかに掃除され、家じゅうでいちばん澄んだ水で満たされていたのに——。

被害者：（解くまで伏せる型。正体は折りたたみの中）

「清潔＝安全」という思い込みを、微生物の化学でひっくり返す。毒は外から入れられたのではなく、毎日少しずつたまっていった。
公式#24 と型が近い（飼い主の善意が命を奪う）。正体を伏せる形は CASE 04 と同じなので、出すなら時期をあける。
ネタばれ：「なるほど」の瞬間・真相と科学・ミスディレクション・学べること・安全・出典

「なるほど」の瞬間

  • ①「彼女」は金魚だった。②汚れに見えたもの（古い水槽のぬめりや緑）こそ、水をきれいにする「生きた浄水場」だった。きれいにしすぎたことが命取りになった。

真相と死因の科学

  • 真相: 夏祭りの金魚すくいで来た金魚。小学生の男の子は翌日、新品の水槽とろ過器を買い、その日のうちに金魚を入れた。水道水のカルキ抜きは毎回きちんと使った。けれど「きれいにしてあげたい」と、毎朝ろ過器のスポンジを水道の水でもみ洗いし、えさも一日に何度もあげた。ふんや食べ残しからはアンモニアが出る。ふつうの水槽では、ろ過材などに住む目に見えない細菌が、アンモニアを害の小さいものに変えている。でも新しい水槽にはまだ細菌が育っておらず、育ちかけても毎朝洗い流された。アンモニアは目に見えず、水は澄んだまま、えらを傷めていった。同じ日にすくって、おばあちゃんの家の古い水槽（少し緑がかった水）に入った金魚は元気だった。
  • 死因の科学: 魚はアンモニアを出す。アンモニアは低い濃度でもえらなどを傷める。水槽では、細菌がアンモニアを亜硝酸に、さらに害の小さい硝酸塩に変える（窒素の循環）。新しいろ過で細菌が十分に育つには6〜8週間かかる、とする資料がある。

ミスディレクションと、その晴らし方・戻し方

  • 水道水の塩素 → カルキ抜きのボトルは、毎回使った分だけ減っている。→ 晴れたら「塩素には気をつけていた。几帳面だった——掃除にも」と、毎朝の掃除の習慣へ向かう。
  • 夏祭りの店でもらった病気 → 体に白い点や傷がない。同じ日の金魚（おばあちゃんの家）は元気。→ 「同じ金魚で、違ったのは水槽」へ戻す。
  • 導入で見せるもの: 男の子、新しい水槽とろ過器（洗いたての白いスポンジ）、減りの早いえさの袋、カルキ抜きのボトル、おばあちゃんの家の古い水槽ともう一匹。
  • 誤差の例: わたしの部屋は[[よごれていた]]。→ 所見「毎朝の掃除」「澄んだ水」で反証。
  • 伏せ字の注意: 解く前の文（失敗の返事・選択肢・ヒント）に「魚」「金魚」「水槽」「えら」「えさ」を出さない（c07 の secretTerms と同じ扱い）。「ガラスの部屋」「部屋の水」「毎朝のごはん」で書く。

学べること／身を守る知恵

  • 魚を迎える前に水槽を「立ち上げる」（細菌を育てておく）。ろ過材を水道水でごしごし洗わない。えさは食べきれる量だけ。水が澄んでいても安全とは限らない。
  • 人の暮らしでも、下水処理場や浄化槽では微生物が水をきれいにしている。

放課後の破裂音

入門の枠のおすすめ入門★1・10分分野：物理・化学監修：不要

事件カード放課後の家庭科室。テーブルの皿の上で、彼女はこなごなに弾けていた。ついさっきまで彼女が入っていた箱の中は、ちりひとつなく、きれいなまま。——彼女は、いつ、どこで弾けたのか？

被害者：ゆで卵（生まれて3日／役目: お弁当のおかず）

見えない圧力が「時間差」で解き放たれる、台所の物理。「レンジの中がきれい＝外で弾けた」という、絵ひとつで解ける推理になる。
「やってみよう」に見える書き方をしない（ワット数・秒数は書かない）。
ネタばれ：「なるほど」の瞬間・真相と科学・ミスディレクション・学べること・安全・出典

「なるほど」の瞬間

  • 弾けたのは箱（レンジ）の中ではなく外。中で静かにたまっていた力が、箸のひと突きで解き放たれた。だから箱の中はきれいだった。

真相と死因の科学

  • 真相: 料理部の中学生が、朝ゆでて殻をむいておいたゆで卵を、お弁当の残りと一緒に温めようと電子レンジにかけた。レンジの中では何も起きなかった。皿に出して、箸で半分に割ろうとした瞬間、卵が弾けた。顔を近づけていなかったので、けがはなかった。
  • 死因の科学: 電子レンジは、食べものの中の水を内側から温める。卵の中で水蒸気ができても、黄身の膜や白身に閉じこめられて逃げ場がなく、中の圧力が高くなる。殻をむいたゆで卵でも同じ。レンジの中で弾けなくても、取り出したあとに弾けることがある。

ミスディレクションと、その晴らし方・戻し方

  • レンジの故障 → 同じレンジで、すぐ前に温めた牛乳とおにぎりはふつうだった。→ 「レンジではなく、温めたものの性質」へ。
  • いたずら（誰かが何かを仕込んだ）→ 火薬のにおいも焦げもない。部屋には部員と先生だけ。→ 部員の証言「箸を入れたとたんに」へ戻す。
  • 「生卵だったのでは？」→ 殻はむいてあった。ゆで卵でも弾ける。
  • 導入で見せるもの: 部員、家庭科の先生、電子レンジ、皿と箸、温めた牛乳のマグカップ、冷蔵庫。
  • 誤差の例: わたしは[[箱の中で]]、弾けた。→ 所見「レンジの中はきれいなまま」で反証。

学べること／身を守る知恵

  • 卵は、生でもゆででも、殻をむいていても、そのまま電子レンジで温めない。
  • 誤って温めたら、冷めるまでさわらない・顔を近づけない。目玉焼きの温め直しでも、口に入れてから弾けてやけどした例がある。

安全の注意／実在事例・統計

  • 書かないこと: 破裂を再現する手順（ワット数・秒数）。「やってみよう」に見える書き方。
  • 実在事例: 東京都生活文化局（2019）に、ゆで卵を温めて外に出したとたんに爆発して手をやけどした例、目玉焼きの温め直しで唇と歯ぐきをやけどした例。国民生活センター「見守り新鮮情報」（2026-06-18）に、ゆで卵の破裂に驚いた高齢者の例。件数の統計は未確認。

助けられた朝

本編のおすすめ 1本編・事故★2・25〜30分分野：生理・工学監修：要

事件カード一月の朝、郊外の家のガレージ。古い車の下から助け出された女性は、駆けつけた兄に「ありがとう」と言って笑った。けれど数分後、崩れるように倒れ、二度と目を覚まさなかった。兄と彼女は、亡くなった父の家をめぐって、何年も口をきいていなかった。

被害者：36歳、図書館司書。古い車を直すのが趣味。

「救助が引き金になる」という逆説。毒は体の中で作られ、解放のタイミングで効く——「誰が殺したか」を「いつ時計が動いたか」に変える切り口。
ネタばれ：「なるほど」の瞬間・真相と科学・ミスディレクション・学べること・安全・出典

「なるほど」の瞬間

  • 助け出された瞬間に、時計が動き出した。毒は外から来たのではなく、彼女自身の筋肉の中にたまっていた。

「なるほど」の瞬間

  • 真相: 帳場をあずかる叔父は旅館の土地を売りたがっていて、売却に反対する若女将を恨んでいた。叔父は、屋根の雪は下からとけると滑りやすくなること、建物から逃げる暖房の熱が屋根の雪をとかすことを、長年の暮らしの知恵として知っていた。前の晩、客のいない二階の大広間（玄関の真上）で大きな暖房を夜通しつけ、天井裏の点検口を開けておいた。逃げた熱が、玄関の上の屋根の雪だけを下からとかし、屋根と雪のあいだがゆるんだ。翌朝、叔父は「早く着くお客さんがいる」と嘘をつき、いつもより早く玄関前の雪かきを頼んで、自分は裏の帳場にいた。大きな雪のかたまりが滑り落ち、彼女を埋めた。
  • 死因の科学（と仕掛け）: 屋根の雪は、屋根との境目がとけるとゆるみ、滑り落ちやすくなる。とかす熱は日ざしや気温だけでなく、建物の中の暖房の熱（屋根から逃げる熱）もある。北海道の研究機関は、つららや「すがもれ」の原因の一つが暖房の熱で、暖房していない家ではつららが極めて少ない、としている。防災科学技術研究所の観測では、屋根の雪が自然に滑り落ちるのは気温がある程度高いときが多い——その朝は、自然に落ちる条件ではなかった。落ちた屋根雪に当たると、けがをしたり、埋まって動けなくなったりする。

ミスディレクション（事故へ）と、その晴らし方・戻し方

  • 「雪国のよくある落雪事故」→ 一日じゅう氷点下のくもり空で、町のほかの屋根は落ちていない。玄関の上だけ、雪と屋根の境目が、とけてまた凍った氷の板になっている。大広間の暖房の灯油タンクが空。天井裏の点検口が開いていた。予約台帳に「早く着く客」はいない。
  • 疑いを向ける別の人: 前の日に若女将と口論した板前 → その朝は市場にいた（レシート）。→ 板前の証言「朝、大広間の前を通ったら、客もいないのに暖房がついていて、廊下まで暑かった」が、熱への道になる。
  • 導入で見せるもの: 叔父（土地を売りたい・帳場）、板前（口論）、旅館の玄関と軒先、大広間の窓の上の見事なつらら（ナレーションで）、くもり空と氷点下、雪かきの道具。
  • 誤差の例: あの朝は、[[日が照って]]、雪がゆるんでいた。→ 所見「一日じゅう氷点下のくもり」で反証。
  • 犯人の名指し: 宣告で名指す形（容疑者は叔父・板前・ほかの従業員）。

  • 屋根の雪は、晴れて暖かい日だけでなく、暖房の熱でも落ちることがある。軒下を通らない、軒下で作業しない。つららの下を歩かない。
  • 雪下ろしは、ヘルメット・命綱・2人以上で。晴れの日ほど要注意（山形県）。高齢者の雪下ろしは、業者や市町村に相談する。

黒く曇った銀の匙

本編のおすすめ 2変わり種・歴史★2〜3・30分分野：化学・栄養監修：要公式との近さ：要確認 #22

事件カード明治の終わり、東京の大きな米問屋。田舎から奉公に来て二年目の娘が、足のむくみと胸の苦しさを訴えたあと、夏の夜に息を引き取った。その日の夕方、寝こんだ娘のために女将が作った卵がゆ。かき混ぜた銀の匙は、黒く曇っていたという。——娘は、毒を盛られたのか。

被害者：19歳、農村から米問屋へ奉公に来た娘。

「銀は毒で黒くなる」という古い毒見の言い伝えを化学で崩し、さらに「足りないものが毒になる」と逆転させる。高木兼寛と森鷗外の論争、鈴木梅太郎のオリザニンという、Dr.STONE 的な科学史を一人の死の謎にできる。
公式#22 と型が近い（食べものと体のしくみ）。くられ先生の過去作で脚気・銀の毒見を扱ったかは未確認。
ネタばれ：「なるほど」の瞬間・真相と科学・ミスディレクション・学べること・安全・出典

「なるほど」の瞬間

  • 毒は皿に入っていたのではなく、皿から抜け落ちていた——米ぬかの中の、小さな栄養。銀の匙を黒くしたのは毒ではなく卵だった。「ぜいたくな白いご飯」が命取りになった。

真相と死因の科学

  • 真相: 娘の村では、ご飯は麦や雑穀をまぜて炊くものだった。米問屋に来てから、娘は毎日、白いご飯をおなかいっぱい食べた。おかずは漬物とみそ汁くらい。精米で米ぬかを取りのぞいた白米には、ビタミンB1がほとんど残らない。B1が足りなくなって脚気になり、足のしびれとむくみ、動悸が出て、ついに心臓が力尽きた（脚気による心不全）。銀の匙が黒くなったのは、卵の黄身から出る硫黄の成分（硫化水素）と銀が反応して、黒い硫化銀ができたため。毒ではない。
  • 死因の科学: ビタミンB1は、ご飯などの糖質をエネルギーに変えるのに欠かせない。白米中心でおかずが少ないと足りなくなり、脚気（神経のしびれ、むくみ、心不全）になる。脚気は江戸時代に「江戸煩い」とも呼ばれた。明治の海軍では高木兼寛が食事を改め、脚気を激減させた。一方、当時は「脚気は伝染病」と考える医学者が多く、陸軍は日露戦争で25万人あまりの患者と約2万8千人の死者を出した。1910年ごろ、鈴木梅太郎が米ぬかから有効成分（のちのビタミンB1）を取り出した。銀の黒ずみは銀と硫黄の化合物の反応で、ゆで卵などから出る硫化水素でも起こる。

ミスディレクションと、その晴らし方・戻し方

  • 毒殺（娘をねたんでいた同じ奉公人の娘／きつく当たっていた女将）→ 同じかゆを味見した女将も無事。台所の銀の箸は、ゆで卵の日にはいつも黒ずんでいた（女中頭の証言）。毒を手に入れた形跡もない。→ ねたんでいた娘の証言「あの子は毎日ご飯を三杯もおかわりしてた。村じゃ白いご飯はお祭りの日だけだったって」が、食べものへの道になる。
  • はやり病（うつる病気）→ 同じ店の手代にも同じ症状があるが、通いの番頭の家族にはうつっていない。医者は「うつる病気かもしれん」と言う（当時、脚気を伝染病と考える医学者が多かった）。→ 「うつったのではなく、同じものを食べていた」へ戻す。
  • 導入で見せるもの: 女将、ねたんでいた奉公人の娘、同じ症状の手代、医者、女中頭、娘の村の話（麦まじりのご飯）、白いご飯、卵がゆ、銀の匙、台所の銀の箸。
  • 誤差の例: わたしは、[[毒を]]、盛られた。→ 所見「女将も同じかゆを口にして無事」「銀の箸は卵の日に黒ずむ」で反証。

学べること／身を守る知恵（いまの暮らしへ）

  • 白米・麺・パン・菓子・甘い飲みものにかたよった食事や、お酒の飲みすぎで、ビタミンB1が足りなくなることは今でもある（MSDマニュアル）。しびれ・むくみ・動悸・だるさが続いたら受診する。玄米・麦・豚肉・豆なども食べる。

  • 書かないこと: 毒の種類・量（「毒を盛られたのでは」という疑いにとどめる）。実在の人物（高木・森・鈴木）を事件の登場人物にすること（科学解剖でだけ触れる）。奉公人への暴力・虐待の描写。
