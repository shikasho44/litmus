# 企画ノート（AI向けのメモ）

**正本は `index.html`（台帳）。** 持ち主に見せる企画の中身は、すべて HTML で出す（2026-10-02 の持ち主の指示）。このファイルは、作業する AI 向けの約束ごとだけを書く。

## 作り方

- 新しい企画ページは `_template.html` を複製して作る（CSS はページの中に入れたまま。外部の読み込みはしない）。ファイル名は `I-番号-短い名前.html`（例: `I-001-tsukuru.html`）。
- 作ったら `index.html` の台帳に1行足し、状態を更新する。
- 調べものは `research/` に HTML で置く（下書きの Markdown は残してよいが、持ち主に見せるのは HTML）。
- 収益化の戦略は別の担当の仕事。`../strategy/` に置く。
- 持ち主に見せるときは、HTML を画面の横に表示する形で送る。

## 守ること

`index.html` の「全部の企画で守ること」を必ず読む（真似できる情報は書かない／唐突なものを出さない／公式28話と先生の10問に重ねない／一般の人の問題は死を扱わない／先生への提案は短く）。

## 続きから始めるとき
