FLOW進め方

  1. 種：一言のアイデアを台帳に足す。
  2. 企画書：1ページにまとめる（どんな遊びか／科学の芯／遊ぶ人にとっての面白さ／先生が面白がりそうな理由／作る大きさ／気をつけること／次の一歩）。
  3. 試作：小さくゲームに入れる。本番の画面は変えず、URL の末尾で切り替えて見られる形にする。
  4. 提案：先生には短く、遊べる形で見せる。質問を重ねない。
  5. 反応：先生の一言を台帳に書く。採用した案は、すぐ形にしてお返しする。
  6. 本採用：開発記録と決定の記録に残して、実装する。

RULES全部の企画で守ること

01

真似できる情報は書かない

量・手順・入手の方法など、個人が真似できることは書かない。

02

唐突なものを出さない

審問やおとりに使うものは先に見せる。疑いを晴らした先は真相へ戻す。

03

重ねない

公式「ジェーンドゥの死因」の公開28話と、くられ先生の10問（過去回のアレンジ）に、死因と仕掛けを重ねない。

04

一般の人の問題は死を扱わない

死・けが・犯罪・実在の人物は、公式の事件だけ。将来、条件を満たした人（アンバサダーなど）や、キャンペーンの応募でこちらが採用を決める形で開放するかは、あとで考える（2026-10-02）。

05

先生への提案は短く

科学監修以外のことで、意見を求めすぎない。見せて、反応を待つ。
