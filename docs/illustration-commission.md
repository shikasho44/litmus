# イラスト依頼の一覧（リトマス審問）

2026-09-27 作成。くられ先生からのご意見「繰り返し出るメインビジュアル・キービジュアルは手描きのものを。印象に残るイラストレーターさんを起用したほうが良い」を受けて、いまゲームで使っている絵を全部洗い出し、どれを手描きに置き換えるかを整理したもの。

いまの絵は、すべて AI 画像生成で作った仮の絵（全29枚。`art-src/CREDITS.md`）。絵はファイル単位で差し替えられるので、置き換えにプログラムの大きな修正は要らない（ホルマだけ、顔の位置の数値を合わせ直す）。

## 1. 結論：どこをお願いするか

| 優先度 | 何を | 枚数 | 理由 |
|---|---|---|---|
| **A. 必ず手描き** | ホルマ（案内役）の立ち絵 4表情 | 1キャラ（4表情） | ほぼ全画面に出続ける、作品の顔。ここが AI 絵だと「手抜き」の印象が一番強く残る |
| **A. 必ず手描き** | タイトルのキービジュアル | 1枚 | 毎回最初に見る画面。SNS で共有される画像（1200×630）もここから切り出す |
| **B. できれば手描き** | 共通の背景（安置室・審問の間・科学の黒板） | 3枚 | どの事件でも毎回、長い時間映る |
| **B. できれば手描き** | 被害者の肖像（事件ごと） | 4枚（4件目を含む） | 事件を解いたときに初めてフルカラーで顔と名前が戻る、感動の山場 |
| C. AI のままでも可 | 事件ごとの背景 | 4枚 | 捜査中ずっと映るが事件ごとに1回。事件が増えるたびに必要になる（量産向き） |
| C. AI のままでも可 | 真相の再構成（文字なし漫画のコマ） | 事件ごとに5コマ（計20） | 事件の最後に1回だけ見る。量が多い |
| 任意 | アプリのアイコン（ホルマの顔） | 1点 | ホーム画面・ブラウザのタブに出る。いまは単純な図形。ホルマが決まれば同じ絵描きさんに小さく描いてもらうと統一感が出る |
| 不要 | ロゴ・ボタン・スタンプ・カード・ガラスの破片・図解 | — | プログラム（文字組み・図形）で描いている。絵の依頼は要らない |

**最低限の依頼は A の2点（ホルマとキービジュアル）。おすすめは A＋B。** C は、ホルマの絵柄が決まったあとで、その絵柄に AI 絵を寄せ直すか、事件を増やす段階でまとめて頼むかを決めればよい。

## 3. どの絵描きさんにも渡す共通の約束

- **雰囲気**: 知的で、少し不穏。ホラーではない。太い墨の線、平塗りの陰影、網点（スクリーントーン）、劇場のような照明。
- **色**: 背景の黒 #0B0D12、紙の白 #F2EFE6、ホルマリンの黄緑 #C6FF3D、警告のマゼンタ #FF2E63、影の冷たい青緑 #1B3A44。ジェーン（ガラスの破片）はシアン #3DE0FF。
- **ホルマの色の約束**: 白衣の白、黄緑の蝶ネクタイ、片目は**琥珀色**のガラス玉 #FFB020（赤にはしない。他作品のマスコットを連想させるため変えた経緯がある）、もう片目は黒いボタン、片耳に標本タグ「No.0」。
- **描かないもの**: 血・けが・遺体・裸、絵の中の文字・ロゴ・署名の透かし。実在の作品やキャラクターに似せない（演出の方向として「ダンガンロンパのような大胆な斜めの構図」を参考にしているが、キャラクターや絵柄は借りない）。
- **納品形式**: PNG（透過が要るのはホルマとアイコン）と PSD（レイヤー分け）。色は sRGB。

## 4. 依頼するときに決めておくこと

- **権利の範囲**: ゲーム内での使用に加えて、トリミング・色調整などの改変、SNS・動画・配信での告知、（将来）有料版や展示・グッズでの使用。有料版や収益分配の可能性があるので、商用利用は最初から含めて相談する。
- **クレジット表記**: ゲーム内のクレジット画面と、公開ページに名前を載せる。
- **AI 学習への利用**: 納品された絵を AI の学習や画像生成の元に使わないことを明記する（気にされる方が多い）。
- **進め方**: ラフ（下描き）→ 線画 → 仕上げ、の各段階で確認。修正回数と追加料金の条件を先に決める。
- **納期**: 正式公開の予定（2026年10月ごろ〜）から逆算する。ホルマが決まらないと他の絵の雰囲気も決まらないので、**ホルマを最初に**。
- **監修の名前**: 「くられ先生の監修予定」と伝えてよいかは、先生に確認してから（返信のメールで確認済みかどうかを見て判断）。

## 5. 費用の目安（見積もりを取るときの参考）

相場は絵描きさんの実績・商用の範囲・独占の有無で大きく変わる。以下はあくまで**見積もりを比べるための目安**で、実際は2〜3人に見積もりを取って決める。

| 依頼 | 目安 |
|---|---|
| ホルマのキャラクターデザイン（清書）＋立ち絵4表情 | 10〜30万円 |
| タイトルのキービジュアル（背景込み） | 10〜30万円 |
| 共通背景 1枚 | 3〜8万円 |
| 被害者の肖像 1枚 | 2〜5万円 |
| 漫画コマ 1コマ | 1〜2万円 |

- A だけ（ホルマ＋キービジュアル）: およそ 20〜60万円
- A＋B（＋背景3枚＋肖像4枚）: およそ 40〜110万円
- 全部（＋事件の背景4枚＋漫画コマ20）: およそ 70〜200万円

同じ絵描きさんに A と B をまとめて頼むと、絵柄がそろい、割安になることも多い。

## 6. 差し替えるときの作業（こちらでやること）

- 絵を受け取ったら、Web 用の大きさ（WebP）に書き出して同じ名前で置き換える（`scripts/art/export_art.py`・`export_panels.py`）。
- ホルマは顔の位置の数値（`public/art/holma/meta.json`）と、タイトル画面の吹き出しの位置（`public/art/key-art.json`）を合わせ直す。
- クレジット画面の「AI 画像生成をもとに制作」の表記を、絵描きさんの名前に書き換える（`src/overlays/Credits.tsx`）。
- 差し替えたら、PC とスマホで全画面を撮影して確認する（`npm run qa`）。
