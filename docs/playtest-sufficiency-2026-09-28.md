# 引き継ぎ：何も知らない人が、審問に足りる所見を集められるか（2026-09-28）

素材制作チャット（aiillustration）で行った検証の結果を、リトマス審問の開発チャットへ渡すメモ。
ゲームの中身（事件データ・画面・判定）は**まだ何も変えていない**。直し方はこのチャットで決める。

## 0. 貼り付け用の要約

> ヨンサンの依頼で、AIプレイテストに年齢・立場の違う9人を足して、4事件を遊ばせた（DeepSeek と GLM で72本）。
> 審問を開いた時点で、全ラウンド分の所見が自力でそろっていたのは72本中30本（約4割）。
> 最終的な正解は66本だが、多くは審問中の「救済」（grant）で埋まっている。
> 集まりにくいのは2か所。
> ・c01「息のない部屋」ラウンド②（警報が鳴りだした、というノイズ）：8/18
> ・c04「白い花の夕餉」ラウンド①（籠に花のない葉まで、というノイズ）：9/18
> 人物では、中学2年生が0/8（犯人がいる前提で聞き続け、事故の所見を取りこぼす）、小学4年生は正解まで届いたのが5/8。
> 詳しくは docs/playtest-sufficiency-2026-09-28.md と bench/reports/playtest/sufficiency_2026-09-28.html。

## 1. 依頼（ヨンサン、9/28 0:0x）

- 水平思考の質問だけで、所見を集められるかを確かめたい。
- いろいろな立場の人を、いろいろなモデルで演じさせる。
- 何も情報を知らない状態から、審問を開くのに足りる所見がどれくらい集まるかを見る。
- 大人から子供まで、いろいろな視点で。
- 必要なら OpenRouter のモデルを使ってよい。

## 2. やったこと

- **人物を9人足した**（`scripts/playtest/personas.ts` の `AGE_PERSONAS`、`--persona ages` で呼ぶ）。
  - 小学4年生（10歳）／中学2年生（14歳）／高校2年生（17歳・理系）／大学生（20歳・文系）
  - 会社員（35歳・推理ゲーム未経験）／子育て中の親（40歳）／高齢者（72歳）／看護師（30歳）／ミステリー好き（45歳）
  - 書いたのは、語彙・知識・根気の違いだけ。事件の中身に触れる知識は書いていない。
  - 既存の5人（beginner / science / clumsy / sharp / adversarial）には手を入れていない。
- **プレイヤーに見せる情報は、既存どおり**。公開の導入文・自分の質問と答え・手に入れた所見だけで、真相や裏のデータは見えない。最大40問、ヒントは3回まで。
- **集計スクリプトを足した**（`scripts/playtest_sufficiency.py`）。
  - 「足りる」の定義：**最初に審問を開いた時点までに手に入れた所見**で、case.json の `debate[].answer.fact` か `alsoAccept` を持っていたラウンドの数。
  - 全ラウンド分を持っていて、審問中の救済（grant）が0回なら「足りた」とする。
  - あわせて、審問を開くまでの質問数・ヒント数・救済の回数・最終の宣告結果を記録する。
- コミット：80d4c12（スクリプトのみ。`bench/reports/playtest` は .gitignore 対象）。

## 4. 読み取れること（確かめていないことを含む）

- **ゲームとしては最後まで遊べる。** 救済と、宣告を3回したら解決扱いになる仕組み（`server/engine/game.ts` 172行付近）があるため、詰まって終わることは少ない。
- **ただし「自分で集めて撃つ」手応えは、c01 と c04 で薄い。** c01 は18本中16本、c04 は18本中12本で、審問のどこかが自力の所見では足りていなかった。
- c01 ②は「警報は鳴らなかった」「電池は前から切れていた」に、質問からたどり着きにくい。プレイヤーは「警報が鳴った」前提のまま審問に入る。
- c04 ①は「籠には花のついたものしか入っていなかった」に、質問からたどり着きにくい。
- 中学2年生の設定（「犯人がいる前提で聞きがち」）では、事故の事件で所見を取りこぼした。**事故だと気づかせる入口**が、導入か質問の例にあってもよいかもしれない。
- 未確認：
  - 人間のプレイヤーでも同じ傾向になるか（AIが人物を演じた結果にすぎない）。
  - モデルを増やすと結果が変わるか（下記の理由で2モデルだけ）。
  - 同じ条件で回し直したときのばらつき（各組み合わせ1本ずつ）。

## 5. 実行と費用

- 再実行（プロジェクトのフォルダで）。事件は1つずつ指定する（`--case c01,c02` のようなカンマ区切りは通らない）。

  ```bash
  npx tsx scripts/playtest.ts --case c01 --persona ages --max-usd 0.3
  ```

- 集計（ラン結果のフォルダを並べて渡す）。

  ```bash
  python scripts/playtest_sufficiency.py bench/reports/playtest/<フォルダ> ... --out bench/reports/playtest/sufficiency_XXXX.html
  ```

- 費用：1本あたり約0.024ドル（判定の Jev と、プレイヤー役で約半分ずつ）。72本で約1.6ドル。
- **GLM-5.3-flash は、推論を切ると 400 で全部失敗する**（「Reasoning is mandatory」）。`LLM_REASONING=low` を付けて回すこと。
- **Qwen3.8-flash は、`LLM_REASONING=low` のままだと返事が空か途中で切れて、遊べなかった**（9本すべて error）。集計からは外した。使うなら推論を切るか、max_tokens を上げる必要がある。
- Gemini 3.8 Flash と Kimi K3 は、プレイヤー役の単価が DeepSeek の約35倍と約140倍。OpenRouter キーの残りは、9/28 0:45 時点で約2.4ドル（キー上限15ドル）なので、使っていない。
