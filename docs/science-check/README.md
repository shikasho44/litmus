## c01「息のない部屋」 判定 ○

**理由**: 大学の地下の保管室で、液体窒素の補充中にタンクがあふれ、気化した窒素が部屋の酸素を押しのけて研究者が亡くなる、という筋書きです。これとほぼ同じ形の事故が実際に記録されています。韓国では、研究棟の地下の狭い区画で、弁が開いたまま空になった大型容器のそばで大学院生が亡くなりました。日本でも、研究所の小部屋で充填中にあふれて研究員が亡くなった事例（厚生労働省）や、北海道大学の低温実験室で2人が亡くなった事故（1992年）があります。「液体は気化すると約700倍にふくらむ」「冷たい窒素は床近くにたまる」「窒素そのものには毒がなく、酸素がゆっくり減ると、息苦しさより先に判断力が落ちる」という仕組みも、公的機関の資料や論文で裏づけられます。ただし、窓のない地下室に大型容器を置く、夜間に排気を止める、酸素濃度計の点検を怠る、深夜に一人で作業する、という本来の安全ルール違反が重なって初めて起きる事故です。そこで本文に「本来はそうしない」と書き足しました。

**現実の裏づけ（主なもの）**
- 厚生労働省 職場のあんぜんサイト 災害事例 No.856（換気のない小実験室で液体窒素の充填中にあふれ、研究員が死亡）: https://anzeninfo.mhlw.go.jp/anzen_pg/SAI_DET.aspx?joho_no=000856
- Kim & Lee 2008（韓国。地下の狭い区画、弁が開いたままの空の容器、大学院生が死亡。床から体が浮いていたので凍傷がなかった）: https://pmc.ncbi.nlm.nih.gov/articles/PMC2526498/
- 北海道大学工学部（1992年8月、低温実験室で2名が液体窒素の気化による酸欠で死亡）: https://scd.eng.hokudai.ac.jp/deanaddress/20230810.html
- 米国 CSB（1992〜2002年の職場の窒素による窒息で80人が死亡、およそ1割は助けようとした人）: https://www.csb.gov/assets/1/6/nitrogen_asphyxiation_safety_bulletin_(6-11-03).pdf
- 徳島大学 事故調査報告書（2025年。窓も換気もないほぼ同じ広さの部屋で、ドライアイスの気化により学生が死亡。室内のファンが換気だと思い込まれていた）: https://www.tokushima-u.ac.jp/fs/5/0/4/6/8/2/_/siryou2_chousakekkahoukokusyo.pdf
- Banzett ほか 2021（酸素がゆっくり減ると、多くの人は息苦しさより先に考える力が落ちる）: https://pmc.ncbi.nlm.nih.gov/articles/PMC10986303/

**今日直したこと（主なもの。全20件中19件を反映、1件は一部反映）**
- 「一人でいた本人が、タンクがあふれたことに約20分気づかなかったのはなぜか」の説明がなかった → 補充中はもともと白い霧が出ているので見分けにくい、本人はタンクに背を向けて作業していた、を追加
- 「息苦しさは二酸化炭素のせい」と言い切っていた → 「息苦しさの合図は二酸化炭素にとても敏感。多くの人は息苦しさを訴える前に考える力が落ちる」に
- 「ひと呼吸で倒れる」 → 「ほんの数回の呼吸で倒れることがある」（生理学の実測に合わせた）
- 発見した警備員が「一歩踏み込んだ途端にめまい」 → 「声をかけるうちにめまい、すぐ引き返した」に。扉を開けておく手段（ドアストッパー）も補った
- 凍傷がない理由（扉の近くに座っていて、液体窒素が届いていない）、死亡推定時刻の根拠、唇の青紫色は決め手にならないこと、を書き足した
- 出典を16件から23件に。出典欄に見えていた内部用語をプレイヤー向けの言葉に直した

## c02「夕暮れの白球」 判定 ○

**理由**: 18歳の女性が、弟の投げた軟式ボールを夕日の逆光で見失って胸に受け、心臓震盪（胸への比較的弱い衝撃が、心臓の鼓動のごく短い「危ない瞬間」に重なって、心臓が細かく震えるだけになる状態）で亡くなる、という筋書きです。日本でも、遊びの最中に逸れた軟式野球ボールが胸に当たって子どもが亡くなった例が2002年に2件あり、国内で集められた49例のうち7例が軟式野球ボールでした。当たったあとボールを拾って投げてから倒れた例、周りの人がしゃくりあげるような呼吸を「息がある」と受け取ってAEDが使われなかった事故も、実際に起きています。ただし、被害者の多くは男性の子どもで、18歳の女性は少数派です（十代の女性の例はあります）。18時12分の逆光は8月上旬〜中旬（東京）でないと成り立たず、倒れて約14分後にまだ心臓が細かく震えていた（電気ショックが効く状態が残っていた）という描写も、起こりうるが少数派です。

**現実の裏づけ（主なもの）**
- 輿水 2009（国内25例。軟式ボールで5歳女児・10歳男児が死亡、ボールを拾って送球したあと倒れた14歳の例など）: https://www.jstage.jst.go.jp/article/jjreanimatology/28/2/28_2_87/_article/-char/ja/
- 輿水 2020（国内49例のうち軟式野球ボール7例。心肺蘇生も電気ショックもなかった例は全例が助からなかった）: https://www.jstage.jst.go.jp/article/jjreanimatology/39/2/39_69/_article/-char/ja/
- Maron ほか 2013（米国216例。95%が男性。倒れて3分以内に蘇生を始めれば生存約40%、3分を超えると約5%）: https://pubmed.ncbi.nlm.nih.gov/23107651/
- Humble ほか 2021（17歳の女性が胸を打たれて心臓震盪。すぐの心肺蘇生と除細動で回復）: https://pubmed.ncbi.nlm.nih.gov/34325875/
- 日本心臓財団（2011年さいたま市、「呼吸がある」と判断されてAEDが使われなかった事故）: https://www.jhf.or.jp/check/aed/school/
- Shibahashi ほか 2023（日本の全国登録。心肺蘇生がないと、倒れて15分で電気ショックが効く状態が残るのは約14%）: https://pubmed.ncbi.nlm.nih.gov/37019616/

**今日直したこと（主なもの。全20件を反映）**
- 「3分以内なら約40%、超えると約5%」の元データの年代が違っていた → 正しい論文（1970〜2012年の216例）に差し替え
- 「強さではなくタイミングがすべて」と読める書き方 → 「強さだけでは決まらない」に（動物実験では遅すぎる球では起きない）。想定質問「ボールの速さは関係ありますか？」も「いいえ」→「一部そう」に
- 熱中症を「前触れがあるかどうか」で見分けるように教えていた → 重い熱中症も突然倒れることがある。決め手は体の芯の温度、に
- 倒れる直前に本人が「めまいもなかった」 → 「目の前がすうっと暗くなって」（倒れるまでの数秒には強い立ちくらみが出ることが多い）
- 約40分の救命処置のあとの解剖なのに「胸には淡い赤みのみ」 → 「救命処置の跡のほかに」に
- 119番で「息はしている」と答えたため、電話の向こうでも心停止だと気づかれにくかった、を追加（なぜ誰も胸を押さなかったかの穴を埋めた）
- ゲームの答え役が事実と違う答えを返す箇所を3つ直した。動物実験の球速を本文から外した。出典を23件から40件に

## c03「雪に残されたもの」 判定 ○

**理由**: 冬山の単独行で吹雪に遭い、捻挫して道に迷った34歳の登山者が、一晩の寒さで低体温症になり、最後は自分で服を脱ぎ（矛盾脱衣）、岩の隙間に潜り込んで亡くなる。薄着の遺体と散らばった防寒具から、はじめは事件が疑われる、という筋書きです。北スウェーデンの凍死51例では約4分の1が「若くしらふで、スポーツ中の人」で、半数を超える例に矛盾脱衣がありました。別の207例の研究では、矛盾脱衣は約3割で、年齢や飲酒、気温とは関係がなく、服は遺体のすぐ近くで見つかることが多い、とされています。アラスカでは雪の登山道に沿って服が点々と落ちていた男性の例、ニュージーランドでは経験のある女性が単独で道に迷い、翌日見つかったときには脱いだ服が体から離れた場所にあった例（2021年。検視官は矛盾脱衣に触れた）があり、服を脱いでいたために事件と疑われた例も法医学の報告に複数あります。事実の誤りは見つかりませんでした。ただ「装備の整ったベテランが一晩もたない」には、疲れ・汗や雪による湿り・ツェルト（緊急用の簡易テント）なし・保温シート未使用が重なる必要があり、その条件が本文に書かれていなかったので書き足しました。また「穴ごもり行動」は仮説の段階の考え方で、屋外の報告は少ないため、言い切りを弱めました。

**現実の裏づけ（主なもの）**
- Albiin & Eriksson 1984（北スウェーデン51例。約4分の1が若くしらふのスポーツ中の人、半数超に矛盾脱衣）: https://pubmed.ncbi.nlm.nih.gov/6497949/

## 残っているリスク

1. **専門家に確かめたい点が残っている**: 3つとも○で、現実に起きるには条件の重なりが要ります。特に、c01「あふれに約20分気づかない」「発見した警備員が無事だった」、c02「倒れて14分後にまだ電気ショックが効く状態だった」「解剖の所見」、c03「服を脱ぎながら十数メートル動けるか」「屋外での穴ごもり行動と呼んでよいか」「死亡までの時間」。質問は [expert-questions.md](expert-questions.md) にまとめました。
2. **「死因の欄が空白」はゲーム上の演出**: 現実には、c01 なら消防や警察が現場ですぐ酸欠を疑うはずです。演出として許されるか、どこかで「ゲーム上の設定」と断るべきかは、監修で相談したい点です。
3. **実際の事故に近い**: c01 は国内の実在の事故（北大 1992年、徳島大 2025年など）、c02 は2002年の子どもの死亡例、c03 はニュージーランドの2021年の事例に形が近いです。ゲームは実在の人物や経緯を借りていません。最近の事故（徳島大）は、ガスも違うためゲームの出典には入れず、この報告の裏づけにだけ使いました。遺族や関係者の目に触れうることは、公開前に意識しておきたい点です。
4. **公式シリーズとの近さ（c01）**: 同じ死因ではありませんが、型が近い回があります。黙っているより先に伝える方が安全です。
5. **絵と本文の小さなずれ**: c03 のコマ4の画像は、本文（最後の十数メートル）より服が遠くまで散らばって見えます（絵の遠近の範囲内と判断。作り直すときの指示は NOTES に記録）。c02 のコマ2の画像が「太陽は地平線のわずか上」になっているかも、目で確かめておくとよいです。
6. **数値をあえて書いていない**: 安全のため、危険になる速さ・時間・濃度の数値は出していません。解説として物足りなくないか、逆に悪用されにくさは十分か、も監修で確かめたい点です。
