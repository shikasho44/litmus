## 1. 結論

**判定：○ 条件つきで起こりうる**（専門家の確認は残る）

### 理由
- **長い圧迫がとけたあとに心臓が止まることは、よく知られている。** 圧迫で傷んだ筋肉からカリウム・ミオグロビンなどが出て、圧迫がとけて血が戻る（再灌流）と全身へ流れ、高カリウム血症で急に心停止することがある（日本救急医学会 医学用語解説集「圧挫症候群」、コトバンク「挫滅症候群」家庭医学館）。圧迫された人の約20%が、圧迫解除後まもなく高カリウム血症または循環血液量の減少によるショックで心停止に至る（Zhang ほか 2024）。
- **救出の直後は元気そうに見えることがある。** 救出の際は痛みを訴えないことがあり、しばらくしてまひ・むくみが出る（家庭医学館）。外見は重症に見えずに、どんどん容態が悪くなる（練馬区「避難拠点運営の手引」）。初期は軽症に見えるが刻々と変化する（厚労科研 分担研究報告書）。
- **家の中の事故でも起こりうる。** 1995年の阪神・淡路大震災では、長時間家屋等の下敷きとなった生存中の傷病者が救出後に心肺停止となる事例が多く発生した（京都市消防局）。372名がクラッシュ症候群と報告された（厚労科研 報告書）。この事件は災害ではなく、車の下敷きという一人の事故に置きかえた。
- **ジャッキの油もれで車が下がることはある。** 油圧ジャッキはオイル漏れを起こしていると、ジャッキアップ中に下がってしまう危険がある（JAF Mate）。ジャッキが外れて車の下敷きになる死亡事故は、いまも報道されている（くるまのニュース 2023）。車の取扱説明書・ジャッキの取扱説明書は、ジャッキだけで支えた車の下に入らないよう警告している（本田技研工業、KTC）。
- **心臓に持病がなくても止まる。** カリウムが極めて高くなると心臓が止まることがある（MSDマニュアル家庭版「高カリウム血症」）。

### ◎ にしなかった理由
- **救出の「数分後」の心停止は、重い側の描き方。** 約20%（Zhang 2024）は災害でがれきの下にいた人を中心とした数字で、両脚だけがひと晩はさまれた一人の事故で、数分以内に心停止まで進むのは起こりうるが重い側。本文は「数分で急に悪くなることも」「ことがある」と書き、必ず起きるとは書いていない。
- **車体が下がって両脚をはさむとき、骨折がないか**は条件しだい（車の重さのどれだけが脚に乗るか、段ボールの上か）。資料で直接は確かめていない（§7）。
- **病院の血液検査で「カリウムが急に増えていた」と分かる**という所見は、心停止のあと・蘇生中の採血の値をどう読むかに専門的な注意がいる（心停止や死後でもカリウムは上がる）。本文は数値を出さず「急にとても多くなっていた」とだけ書いた（§7）。

## 4. 反論してみる（専門家ならどこを突くか）と、その扱い

### 4-1. 「両脚だけ、ひと晩で、救出数分後に心停止は重すぎないか」 → **『ことがある』と書いた**
重い側の描き方であることは認める（§1）。本文は「数分で急に悪くなることも」「心臓が止まることがある」と可能性で書いた。時間数のしきい値は書いていない。

### 4-2. 「助ける前に医療を待つべきだ、と書かないのか」 → **書かない（安全の方針）**
災害医療では救出前の輸液がすすめられる（Zhang 2024）ことは「災害の現場では」に事実として書いた。一般の人への行動は「助けながら119番し、はさまれていた時間を伝えて指示を受ける」までにした。「助けるな」と読める言い方は避けた（よくある誤解2で、はっきり打ち消した）。

### 4-3. 「兄が責められて読めないか」 → **誰のせいでもない、と各所に書いた**
whyHere の最後の段落、finale、別れの言葉（「助けてくれたこと、まちがってない」）、所見の判定メモ。仮定の問い「兄がもっと早く来ていれば助かった？」は答えない想定質問にした。

### 4-4. 「病院のカリウムの値は、心停止や蘇生のせいでも上がるのでは」 → **数値を出さず、専門家への質問に回した**
所見 F20 は「急にとても多くなっていた」だけ。死因の判断は、圧迫の経過・脚の筋肉の損傷（F21）・解放直後の発症（F17）・心臓に病気がない（F18）を合わせた形にしてある。

### 4-5. 「骨折なしで両脚がはさまれるか」 → **専門家への質問に回した**
車の重さのどれだけが脚に乗るかしだい。本文は「骨は折れておらず」と書いた。

### 4-6. 「寒さ（低体温）や脱水も関係するのでは」 → **ミスディレクションとして否定したが、言い過ぎない**
断熱されたガレージで体温は「少し低いくらい」とした。寒さが主因ではないことは F26 で示したが、「寒さはまったく関係ない」とは書いていない。

### 4-7. 「119番の指令員が何と言うか」 → **具体的な指示は書かない**
「指示を受ける」「指示に従う」までにした。

## 6. 公式シリーズ（ジェーン・ドゥの死因）との重なり

[overlap.md](overlap.md) §3 の28問（動画29本）の正解を一つずつ見直した。**クラッシュ症候群（長い圧迫の解除後の急変）を答えとする回はない。重複なし**（種の資料の判定「近い公式回: なし」と一致）。

弱い近縁（型の一部が似ているだけ）:

| 回 | 共通点 | 違い |
|---|---|---|
| #20 死者は女騎士!?（2023-10-27） | 最後は「磁石とコンテナに挟まれた」 | 挟まれたその場の力による死。圧迫の「解除のあと」に体の中から起きる死ではない |
| #1 第一回（2021-11-23） | 車（トラック）と重い物の事故 | 慣性で滑った鉄筋が刺さる。物理の事故で、体の中の変化ではない |
| #27 GENKI LABO 後編（2026-01-30） | 重い物（バーベル）が体に当たる | 低血糖で意識を失ったのが芯 |

「救助が引き金になる」「毒は体の中でできる」という芯、ミスディレクション（不仲の兄）、教える内容（ジャッキ・119番・病院・家具の固定）は、どの回とも重ならない。監修依頼では「近い回なし」と伝えてよい。見られなかった回（有料会員向け・生配信・イベント）は overlap.md §6 のとおり確認できていない。

## 7. 監修者（くられ先生）に確認してほしい点

1. 両脚（太もも〜すね）がひと晩、車体と床にはさまれた36歳女性が、救出の数分後に高カリウム血症による致死的な不整脈で心停止する、という筋の妥当性（重い側として描いてよいか）。
2. 車体が下がって脚をはさむ形で、骨折なし・外出血なしはありうるか。
3. 救出直後に「話もでき、笑って礼を言う」描写。
4. 病院の血液検査で「カリウムが急に増えていた」と分かる、という所見の置き方（心停止後・蘇生中の採血の値の読み方）。
5. 一般の人への言い方：「助けながら119番し、はさまれていた時間を伝えて指示を受ける」「元気そうでも必ず病院へ」で足りるか。
6. ジャッキの描き方（古い油圧ジャッキの油もれで車がゆっくり下がる）でよいか。
