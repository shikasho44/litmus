CONCLUSION1. 結論（いちばんおすすめの形）

  1. 今の8件は無料のまま。新しい事件を「事件ファイル」として買い切りで売ります。最初の目玉は、くられ先生の10件です（1,500円前後。1件は無料で試せる形）。
  2. 広告は補助です。解いた後の画面と、見たい人だけの「スペシャルヒント」に限ります。【試算】広告の収入は AI の費用の2〜5割ほどです。広告だけだと、遊ぶ人が増えるほど赤字が増えます。
  3. もう一つの柱は学校・自治体です。出前授業や探究学習の教材として売ります。1件で数万円になり、ヨンサンさんのつながりを生かせるので、初期費用 約30万円の回収にいちばん確実な道です。
  4. くられ先生には「先生の事件パックの売上（決済手数料を引いた額）の30%」をお分けする案を、売り始める1か月前に、数字と覚書の下書きつきで出します。今は交渉しません。
  5. 正式公開は無料のまま出します。遊ばれ方（完走率・1事件の AI 費用）を測ってから、有料を始めます（3か月後めど）。

各候補のくわしいメモ（出典つき）

① 解いた後の広告

  • Web 広告の目安は、1ページの表示あたり0.2〜0.5円です［1］。10万ページで月3万円という目安もあります［2］。
  • 子ども向けとして扱うと、興味に合わせた広告が止まり、単価はさらに下がります［8］。死や毒を扱うので、審査で慎重に見られるおそれがあります（血の描写や手順は書いていないので、通る見込みはあります）［8］。
  • 今の画面は安全のため外部の読み込みを止めています（CSP）。広告を入れるなら、この設定とプライバシーポリシーの書き換えが要ります。

② スペシャルヒント

  • Web で「見るとごほうび」の動画広告を出す道は3つです。Google の H5 Games Ads（ベータ版・申し込み制。AdSense の承認が前提で、承認は保証されない）［5］、Ad Manager の Web 向けリワード広告［6］、AdSense の Offerwall（2026-04-13に一般提供。ページ単位で鍵をかける形なので、1画面で動くこのゲームには合わせにくい）［7］。
  • 決まり：見るかどうかは利用者が選ぶ。ごほうびにお金の価値を持たせない［5］。
  • 単価：日本のスマホアプリの動画リワードは1,000回あたり約10.8ドル［3］。Web はこれより低めと見ました。開発者の実例で1再生0.5円［4］。
  • Web では「最後まで見たか」をサーバーで確かめにくいです。ずるされても困らない中身（死の種類だけ）にしておくのが合います。対戦では使えないようにし、初回の解決の記録には「ヒントあり」の印を付けます。
  • 承認が取れないときの代わり：「捜査10分で解放」にする、または応援パス（買い切り・広告なし）で開ける。

③ 事件パック

  • 似た商品の値段：Steam の追加事件は3件で700円［10］。マダミスアプリ「ウズ」の1本は400〜800円［11］。AI が出題者の『みんなでウミガメのスープ』は880円［12］。AI のウミガメのスープのアプリでは「広告なし」が300円［13］、脱出ゲームのアプリではヒント用のコインが180円〜、広告なしが2,880円［14］。
  • アカウントは作らず、「購入コード」で開く形をおすすめします。今の仕組み（サーバーと D1）に足しやすく、学校・イベント・先生のファンクラブにもコードでまとめて渡せます。
  • 答えはサーバーにだけ置いているので、コードがないと有料の事件は遊べません。答えがブラウザに入る静的版には、有料の事件を入れません。
  • 小さく足せるもの：応援パス（買い切り500円前後。広告なし、スペシャルヒントも広告なし、クレジットにお名前）。AI のウミガメのスープのアプリの「広告なし300円」が参考です［13］。

④ 全部入りの買い切り

  • 分かりやすい反面、あとで作る事件の資金が入りません。「◯月までの新作込み」と約束すると、遅れたときの対応が重くなります。

⑤ 月額・シーズンパス

  • 月額には「定期購入」の表示と解約の決まりがあります［22］。決済会社の月額機能は、売上の0.7%が上乗せです［18］。毎月2件以上の新作を出せるようになってからで十分です。先に出すなら、決まった数の新作をまとめて前払いする「シーズンパス」（買い切り）の方が扱いやすいです。

⑥ 学校・塾・自治体・科学館

  • 価格の目安【試算】：出前授業 1コマ4.5万円〜（税別）＋交通費［16］。授業用ライセンス 1クラス 年1.5万円、または生徒1人 年500〜1,000円（探究教材の例 生徒1人 年1,430円［15］、米国の脱出型教材 1クラス 年99ドル〜［17］）。自治体・図書館・科学館のイベント 1日10〜20万円（公開審問2〜3回、運営込み）。協賛の事件（安全の啓発など）1件20〜50万円（「PR」の表示が必要［30］）。

  • 強み：学校は毎年生徒が入れ替わるので、同じ事件を毎年使えます（一度きりの弱点が消える）。AI が自由に話さない作り（返事は書き溜めた台詞）は、学校に説明しやすい点です。
  • 注意：先生の「教育目的利用ガイドライン」は、会費を取る講習での利用を認めていません［33］。先生の事件を有料の授業で使うなら、覚書で別に決めます（または学校版はヨンサンさんの事件で組みます）。

WITH DR. KURARE5. くられ先生との分け方の考え方

「科学者が安く使われることはあってはならない」とコラムに書いておられます［34］。お金とクレジットは先に、はっきり。名前の出ない報道向けの監修は受けておられない。打ち合わせより短い文章。書類は依頼する側が作る［34］。

基本の考え（4つ）

  1. 先生の事件が売れたら、売れた分だけお返しします。10万円の見直しではなく、上乗せのお礼です。
  2. 数字を先に、短く出します。「あとで考える」にしません。
  3. 書類はこちらで全部作ります。先生は「OK」と返すだけで済むようにします。
  4. お名前とリンクをはっきり出し、遊ぶ人を先生の動画・本・グッズへ送ります。

RISKS8. 危ないところ

危うさ何が起きるか減らし方
AI の費用が跳ねる話題になると1日に数千事件。上限に当たると簡易判定に落ちて質が下がる。判定の AI（Jev）は OpenRouter の試験版の窓口で、値上げや終了もありうる。費用はドル建て。専用キーと上限。有料の事件は上限の外。無料の事件は安い設定も選べる。収入とセットで上限を上げる。
子ども向けの広告の質合わない広告や、だます広告が出る。興味に合わせた広告を止める。カテゴリを止める。学校版と入門の事件には広告を出さない。出てくる広告を定期的に見る。
コミュニティの反発「無料だったのに」「広告だらけ」「先生の名前でお金もうけ」。今の8件はずっと無料。捜査中の広告なし。解く力は売らない。売上の一部が監修者に届くことを書く。
先生との関係期待のずれ、権利の行き違い、お名前の使いすぎ。売る前に数字つきで提案。書類はこちらで作る。宣伝は先生の了承を取ってから。頼みすぎない。
一度きりの中身解いたら終わり。配信やネタばれで価値が下がる。新作を決まったペースで足す。対戦・日替わりで遊び直し。学校は毎年生徒が入れ替わる。
審査広告・決済・ストアが承認されない、遅れる。広告なしでも成り立つ計画にする。早めに申し込む。
子どもの課金トラブルオンラインゲームの相談は2025年度に6,234件。契約した人が小中高生の相談は2022年度に4,024件、平均 約33万円［28］。買い切りだけ。高額にしない。保護者の同意の一文。取り消しの窓口。
人の時間学校の仕事は人が動く。事件づくりも続く。学校の先生が自分で授業に使える版も用意する。価格に準備の時間を入れる。
