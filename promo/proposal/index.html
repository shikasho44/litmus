CASE 01 · 約12分

たたみかけのタオル

九月はじめの暑い午後。2階の和室で、取りこんだ洗濯物のそばに、67歳の女性が座りこむようにして倒れていた。暑さか、心臓か。

監修
お願いしたい
真相と科学（ネタばれ）

バスタオルのひだにひそんでいたアシナガバチに手首を刺された。前の年のひと刺しで体が毒を覚えていて（感作）、二度目で全身のアレルギー反応、アナフィラキシーが起きた。血圧が下がり、のどがむくんだ。学べること：二度目が危ない理由、あおむけで足を高く・119番・エピペン、洗濯物は取りこむ前にはたく。

CASE 02 · 約10分 · 入門

背のびした牛乳びん

夏休みの朝、冷凍庫の中で、二本ならんだ牛乳びんの一本にひびが入っていた。口からは白い柱がのびている。

監修
身近な科学のため、監修の対象外と考えています
真相と科学（ネタばれ）

満タンのびんのまま凍らせた。牛乳の約87%は水で、水は凍るとかさが約1割（約9%）ふえる。行き場のない分が口から氷の柱になって押し出され、胴にひびを入れた。すきまのあった半分のびんは無事。

CASE 03 · 約12分 · 入門

氷点下の雪だるま

一日じゅう氷点下の晴れた日。庭の雪だるまの頭が落ちていた。首のまわりだけが、細くやせていた。

監修
身近な科学のため、監修の対象外と考えています
真相と科学（ネタばれ）

妹が巻いた黒い毛糸のマフラーが日の光を吸って0℃をこえ、ふれている首の雪をとかした。気温は日かげの空気の温度で、日なたの黒いものはそれより温まる。白い雪は光をはね返すので胴や頭は無事。

CASE 04 · 約15分 · 入門

水のそばの渇き

朝の食卓で、彼女は首をがっくりと曲げたまま見つかった。ひどく渇いていた。すぐそばに、きれいな水がたっぷりあったのに。

監修
身近な科学のため、監修の対象外と考えています
真相と科学（ネタばれ）

「彼女」は母の日の赤いバラ。紙に包まれて7時間窓辺に隠されるあいだに、切り口から茎の道管に空気が入り、空気の中で切り戻したため、花びんの水を吸い上げられずに首が曲がった。水の中で茎を切ったおばあちゃんのバラは元気。

CASE 05 · 約25分

息のない部屋

大学の研究棟、窓のない地下の試料保管室。明け方、若い女性研究者が棚にもたれて座ったまま見つかった。傷も、争った跡もない。

監修
お願いしたい
真相と科学（ネタばれ）

深夜、一人で液体窒素を補充するうちにタンクがあふれ、気化した大量の窒素が部屋の酸素の割合を下げた。排気の停止、閉まった防火扉、電池切れの酸素濃度計、一人作業が重なった事故で、窒素には毒がなく息苦しさが出にくいため危険に気づけなかった。他殺の線（もう一枚の入館カード、外されたストッパー、前日の口論）は証拠で晴れる。

CASE 06 · 約35分

夕暮れの白球

八月の夕暮れの河川敷。弟の投球練習に付き合っていた少女が、突然崩れ落ちた。その少し前、土手の上では見知らぬ男の怒鳴り声が響いていた。

監修
お願いしたい
真相と科学（ネタばれ）

夕日の逆光で見失った軟式ボールが左胸に当たり、心臓の拍動のごく短い受攻期に重なって心室細動が起きた（心臓震盪）。大人たちは熱中症と思い込み、死戦期呼吸を「息がある」と受け取ったため、胸骨圧迫も AED も使われなかった。土手の男は無実。

CASE 07 · 約35分

雪に残されたもの

一月の雪山。戻らなかった女性が、岩の隙間で見つかった。防寒具は周りの雪の上に点々と落ち、カメラには霧の中に立つ黒い人影が写っていた。

監修
お願いしたい
真相と科学（ネタばれ）

ホワイトアウトで道を外れ、重い低体温症（凍死）に。末期に体が熱いと錯覚して服を自分で脱ぎ（矛盾脱衣）、岩の隙間へ這い込んだ（穴ごもり行動と考えられる）。霧の人影は自分の影（ブロッケン現象）、裂けた袖は岩の角によるもの。

CASE 08 · 約40分

白い花の夕餉

四月の終わり、山あいの古民家。摘みたての山菜の夕食のあと、植物画家の女性がその夜のうちに亡くなった。春の山ではよくある、山菜の採り違え——誰もがそう思った。

監修
お願いしたい
真相と科学（ネタばれ）

担当編集者が盛り付けのとき、彼女の小鉢にだけ刻んだトリカブトの若葉を混ぜた、採り違えの事故に見せかけた殺人。アコニチン類による致死性の不整脈。籠に毒草がないこと、毒が彼女の小鉢だけから出たことなどで故意と分かる。学べること：葉ではなく白い花を一本ずつ確かめる、迷ったら採らない・食べない、すぐ受診・吐かせない。

科学の確認

科学の確認で伺いたいこと

監修をお願いしたい5件について、資料だけでは決めきれなかった点を、事件ごとに2〜3つに絞りました。どれも「はい／いいえ」でお答えいただける形です。

より詳しい資料もご用意しています。必要でしたらお申しつけください。

ネタばれを含みます

CASE 01「たたみかけのタオル」
  1. 前の年に刺されて大きくはれただけ（全身症状なし）の67歳の女性が、約1年後にアシナガバチに一度刺されて、亡くなるほどのアナフィラキシーになる。「まれだが起こりうる」と書いてよいでしょうか。
  2. 死因の判断の根拠を「のどの入り口のむくみ」「血液のトリプターゼの上昇」「刺し跡とハチ」「心臓・脳に病気なし」の組み合わせにしています。実務と合っているでしょうか。
  3. 覚えて帰る点を「あおむけに寝かせて足を高く」「急に座ったり立ったりしない」「119番」「処方された人はエピペン」にしています。一般向けとしてこれでよいでしょうか。

公式シリーズにもアナフィラキシーの回（#15・#25）がありますが、きっかけと謎の芯は別にしています。

CASE 05「息のない部屋」
  1. 補充中にもともと出ている霧にまぎれて、タンクに背を向けて作業していた研究者が、あふれ始めに気づかないまま酸欠で倒れる。この筋書きは現実に起こりうるでしょうか。
  2. 「息苦しさの合図は、主に体内の二酸化炭素の増加に反応する。酸素がゆっくり減る場合、多くの人は息苦しさを訴える前に考える力が落ちるか意識を失う」という説明は、一般向けとして正確でしょうか。
  3. 安全の言葉を「ほんの数回の呼吸のうちに、警告らしい警告もないまま意識を失うことがある」としています。これでよいでしょうか。

公式シリーズの #16（ドライアイス）・#26（ろうそく）と型が近いですが、窒素で酸素だけが減る点で仕組みは別と考えています。

CASE 06「夕暮れの白球」
  1. 18歳の女性の胸に、小学5年生が全力で投げた軟式ボールが当たって心臓震盪が起きる。この設定は現実に起こりうるでしょうか。
  2. 仕組みを「心臓の拍動のごく短い時期（受攻期）に胸への衝撃が重なると心室細動が起きる。遅すぎる球では起きず、実際はその競技でふつうの速さの球で起きることが多い」と説明しています。一般向けとして正確でしょうか。
  3. 周りの大人が熱中症と思い込み、死戦期呼吸を「息がある」と受け取って胸骨圧迫が行われなかった、という場面は、指令員や周りの人を責めない書き方として問題ないでしょうか。
CASE 07「雪に残されたもの」
  1. 震えが止まった段階の人が、捻挫した足で十数メートル、よろめき這いながら、帽子・手袋・上着を順に脱ぐ（矛盾脱衣）。これは生理的に起こりうるでしょうか。
  2. 健康でしらふの34歳が、−15℃前後・強風・ぬれた服・ツェルトなしの条件で、行動を止めてから約9〜11時間で亡くなる経過は自然でしょうか。
  3. 岩の隙間へ自分から入った行動を「穴ごもり行動と考えられる」と書いてよいでしょうか。
CASE 08「白い花の夕餉」
  1. ゆでたニリンソウのおひたしに刻んだトリカブトの若葉が混ざっていた場合、食べる人は気づきにくい、としてよいでしょうか（混ぜ方は書いていません）。
  2. 毒の働きを「ナトリウムチャネルの門を開きやすく、閉じにくくする」と説明しています。一般向けとして適切でしょうか。
  3. 見分け方の図に葉や根の違いも載せ、結びで「葉だけで見分けようとしない。白い花を一本ずつ確かめ、迷ったら採らない・食べない」としています。「見分けられる」と誤解させる心配はないでしょうか。
